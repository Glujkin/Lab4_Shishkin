## Описание проекта

Данная лабораторная работа направлена на закрепление навыков работы с системой контроля версий Git, языком разметки Markdown, терминалом и проектной структурой. В ходе работы были созданы клиентская и серверная части приложения, выполнена практика работы с файловой системой и оформлена профессиональная документация.
